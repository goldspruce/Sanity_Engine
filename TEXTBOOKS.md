# Sanity Engine Textbook Library & Corpus Index

This directory contains the authoritative reference textbooks used by **Sanity Engine** for literature retrieval (Channel B), adversarial falsification, and quote verification.

All books are ingested from `Textbooks/` into plain-text chunks in `corpus/` using:
```bash
.venv/bin/python ingest_textbooks.py
```

## Using with Google NotebookLM

### 🔗 Preloaded NotebookLM Workspace (Zero Setup)
For team members, peer reviewers, and researchers, a **preloaded Google NotebookLM workspace** containing the complete textbook library is shared directly via link.

> **Accessing the Preloaded Workspace:**
> - Reviewers can open the shared NotebookLM link directly to begin cited Q&A, generate Audio Overviews, and verify claims across all 11 textbooks with zero file uploading or configuration.
> - To customize the URL displayed in generated reports, add `NOTEBOOKLM_URL="https://notebooklm.google.com/notebook/your-shared-id"` in your `.env` file.

---

### Alternative: Creating Your Own NotebookLM Workspace
If you wish to create a custom, private notebook from scratch:

#### Step 1: Pack the Corpus into Notebook-Friendly Files
Google NotebookLM has per-source word and file size limits. Run the packer script to slice your corpus into formatted files:
```bash
.venv/bin/python pack_for_notebook.py --corpus corpus --out notebook_pack --max-words 200000
```
This produces clean files in `notebook_pack/` along with a `manifest.csv` mapping each chunk back to the exact source textbook.

#### Step 2: Upload to NotebookLM
1. Open [Google NotebookLM](https://notebooklm.google.com).
2. Create a new notebook (e.g., *"Sanity Engine Reference Library"*).
3. Upload the files from `notebook_pack/` (or upload specific PDFs from `Textbooks/`).
4. Ask specific questions about the untested claims, citations, or edge conditions generated by the Sanity Engine report!
