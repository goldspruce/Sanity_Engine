# Sanity Engine Textbook Library & Corpus Index

This directory contains the authoritative reference textbooks used by **Sanity Engine** for literature retrieval (Channel B), adversarial falsification, and quote verification.

All books are ingested from `Textbooks/` into plain-text chunks in `corpus/` using:
```bash
.venv/bin/python ingest_textbooks.py
```

## Using with Google NotebookLM

To review literature deeply, test hypotheses interactively, or examine untested claims using **Google NotebookLM**:

### Step 1: Pack the Corpus into Notebook-Friendly Files
Google NotebookLM has per-source token/word limits. Run the packing script to split your corpus into formatted slices:
```bash
.venv/bin/python pack_for_notebook.py --corpus corpus --out notebook_pack --max-words 200000
```
This produces clean files in `notebook_pack/` along with a `manifest.csv` mapping each chunk back to the exact textbook.

### Step 2: Upload to NotebookLM
1. Open [Google NotebookLM](https://notebooklm.google.com).
2. Create a new notebook (e.g., *"Biomechanics & Neurophysiology Corpus"*).
3. Upload the text files from `notebook_pack/` (or upload specific PDFs from `Textbooks/`).
4. Ask specific questions about the untested claims or edge conditions generated by the Sanity Engine report!
